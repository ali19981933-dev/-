### إصلاحات حرجة
| # | الميزة | الشرح |
|---|--------|-------|
| 1 | **نسخة احتياطية كاملة** | زر «نسخة كاملة (بالمرفقات)» يصدّر السجلات **مع كل الصور وملفات PDF** في ملف واحد، ويُستعاد بنفس الزر |

## ثانياً: الإعداد على مستودع جديد (حساب جديد)

### الخطوة 1 — جهّز حساب GitHub
1. أنشئ حساباً جديداً على `github.com` (أو استخدم حساباً آخر تملكه).
2. لا تحتاج إنشاء أي مستودع يدوياً — **التطبيق ينشئ مستودع البيانات الخاص تلقائياً** باسم `bsr-data` عند أول اتصال.

### الخطوة 2 — شغّل التطبيق
اختر واحدة من طريقتين:

**أ) مباشرة (الأسهل):** انسخ ملف `index.html` إلى كل جهاز وافتحه بالمتصفح. يعمل كاملاً بدون إنترنت، والمزامنة تحتاج إنترنت فقط.

**ب) عبر GitHub Pages (رابط موحد للجميع):**
1. في حسابك الجديد أنشئ مستودعاً عاماً (Public) باسم مثل `ktbe-app`.
2. ارفع ملف `index.html` إليه (Add file → Upload files → Commit).
3. من Settings ← Pages ← اختر Branch: `main` ثم Save.
4. بعد دقيقة سيصبح التطبيق متاحاً على:
   `https://<اسم-حسابك>.github.io/ktbe-app/`
5. ضع هذا الرابط في متصفح كل الأجهزة وأضفه للشاشة الرئيسية.

### الخطوة 3 — اربط التخزين السحابي
1. عند أول فتح تظهر نافذة «الاتصال بالتخزين السحابي».
2. اضغط رابط صفحة إنشاء التوكن داخل النافذة، واجعل Expiration = «No expiration»، ثم Generate token.
3. انسخ التوكن والصقه، وتأكد من اسم المستودع `bsr-data` (أو غيّره كما تشاء)، ثم اضغط **اتصال**.
4. ستظهر الحالة أعلى الصفحة: «● متصل» مع وقت آخر مزامنة.

### الخطوة 4 — أنشئ حساب المدير
1. اضغط شارة الحالة أعلى الصفحة ← «تخطي» غير مطلوب إن كنت متصلاً.
2. من تبويب **👤 المستخدمون** ← «تفعيل دخول الموظفين» واتبع الخطوات.
3. **مهم:** سيظهر لك ملف `vault.json` — نزّله وارفعه في **مستودع التطبيق** (مثل `ktbe-app`) بنفس الاسم، ليتمكن بقية الأجهزة من تسجيل الدخول.
4. أضف حسابات الموظفين من نفس التبويب (اسم + مستخدم + كلمة مرور 8 أحرف+ + الصلاحية مدير/موظف).

### الخطوة 5 — (اختياري) انقل بيانات النظام القديم
1. افتح **المنظومة القديمة** ← تبويب الأرشيف ← زر «⬇ نسخة كاملة (بالمرفقات)» إن وُجد، وإلا «تجهيز النسخة».
2. افتح **المنظومة الجديدة** ← الأرشيف ← بطاقة النسخة الاحتياطية ← الصق النص ← «استيراد».
3. الجديد يفهم صيغتين: النسخ القديمة (سجلات فقط) والجديدة v2 (سجلات + مرفقات).

## ثالثاً: طريقة العمل اليومية المقترحة

- **كتاب صادر:** إدخال البيانات ← (المبلغ يُفصَّل تلقائياً) ← معاينة وتعديل بالنقر المباشر على أي نص ← طباعة (يُحفظ ويؤرشف تلقائياً) ← أرفق صورة الكتاب الموقّع لاحقاً.
- **كتاب وارد:** التقط صورة بالكاميرا أو ارفع مجلداً كاملاً ← «قراءة غير المقروء» يستخرج البيانات تلقائياً ← راجع ← سجّل الإحالات مع تاريخ استحقاق للمتابعة.
- **نهاية كل أسبوع:** افتح شبّاح «⏰ متأخرة» وعالج المتبقي، ثم راجع «لوحة التقارير».
- **نهاية كل شهر:** نزّل «نسخة كاملة (بالمرفقات)» واحفظها في مكان آمن خارج GitHub.

## رابعاً: ملاحظات أمنية

1. **المستودع خاص (Private)** — النظام يرفض الاتصال بمستودع عام ويحذّرك.
2. **التوكن لا يُعرض أبداً** — مشفر داخل ملف الدخول؛ لو اشتبهت بتسريبه: احذفه من GitHub وأنشئ غيره ثم حدّث الاتصال في كل جهاز.
3. صلاحية الموظف (غير المدير) تخفي: حذف الكتب، المحذوفات، المستخدمين، ومحرر القوالب.
4. النسخة الاحتياطية الكاملة تحتوي بيانات حساسة — احفظها مشفرة أو في مكان مؤمّن.

## خامساً: حل المشكلات الشائعة

| المشكلة | الحل |
|---------|------|
| «فشلت المزامنة» | اضغط شارة الحالة لعرض السبب، أو زر «فحص التشخيص» |
| التوكن منتهي | أنشئ توكن جديداً ← نافذة الاتصال ← حدّث |
| المرفقات لا تظهر على جهاز آخر | انتظر انتهاء المزامنة — تُنزَّل عند فتحها لأول مرة |
| القراءة الذكية (OCR) لا تعمل | تحتاج إنترنت في أول استخدام لتحميل اللغة العربية |
| نسيت كلمة مرور المدير | من جهاز آخر يعمل، أدخل بحساب مدير آخر وغيّرها؛ وإلا احذف `bsr_vault` من جهاز المدير وأعد الإعداد |
